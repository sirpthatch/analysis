# Oh Crash Data, where are you?

For some reason NYC is about 3 months late publishing its data about [Vehicle Collisions](https://data.cityofnewyork.us/Public-Safety/Motor-Vehicle-Collisions-Crashes/h9gi-nx95/about_data).  This has been reported on in [StreetsBlog](https://nyc.streetsblog.org/2026/09/09/empty-quarter-citys-crash-database-hasnt-been-updated-in-three-months) and [Hoodline](https://hoodline.com/2026/09/nyc-s-crash-data-has-been-frozen-since-june-hiding-thousands-of-wrecks/), and it affects useful services like [CrashMapper](https://crashmapper.org/#/).  The last time that that the [dataset](https://data.cityofnewyork.us/Public-Safety/Motor-Vehicle-Collisions-Crashes/h9gi-nx95/about_data) has been updated on OpenData is June 15, 2026, and there is a delightfully unhelpful message at the top stating:

> This dataset is temporarily not updating while its automated update process is being fixed. This fix is expected to be completed during the month of August.

Seeing as we are nearing the end of September and this is still not working, let's see if we can help the city out here a bit!
